Before you start: 5 rules

      
The computer is strict. Your pseudo code only runs if it follows these rules.

      
    
        
  1. 
          Commands in UPPERCASE.
          SET, PRINT, IF, THEN, FOR EACH, END IF…
          print "hi" PRINT "hi"
        
    2. 
        
  2. 
          Indent with exactly 4 spaces inside every block (the Tab key adds 4 spaces). Each level inside adds 4 more.

    IF score > 50 THEN
····PRINT "Pass"
END IF
    
        
    3. 
        
  3. 
          Close every block with its END: END IF, END FOR, END WHILE, END FUNCTION.
        
    4. 
        
  4. 
          Use SET to give a value and put spaces between words:
          x=5 SET x = 5
        
    5. 
        
  5. 
          Text goes inside quotes and is joined with +:
          PRINT "Total: " + total
        
    6. 
      

      
Not sure how to write something? Open the Glossary. Error messages tell you the line number to fix.
        Your class uses a command the runner doesn't know? Teach it in Glossary → My commands.
